# Generated outputs

<code>verify_all.py</code> writes raw JSON, rate fits, and verdicts here.
Runtime outputs are ignored by Git until a run is recorded with its source
commit, environment, parameters, dataset provenance, and an independent
checker.

The previously tracked <code>verdict.json</code> and
<code>verify_run.log</code> were generated by the superseded
<code>repro/src/verify_mwgrad.py</code> toy/proxy verifier and conflicted with
the publication README and gate. They were removed from the publication
surface rather than presented as evidence for the root
<code>verify_all.py</code> suite.
