# Legacy proxy verifier

The files in this directory are retained only as provenance for the first
finite-dimensional toy attempt. They are not used by the root
<code>verify_all.py</code> suite and must not be presented as evidence for the
paper's claims.

The legacy verifier uses five-dimensional convex quadratics, does not
implement the paper's Gaussian-family flow, and labels its multi-task check a
synthetic proxy. Use the root verifier for the current implementation.
